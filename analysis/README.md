# Local analyses

Scratch analyses that are **not** published to [pdenumbers.org](https://pdenumbers.org/).

The live LEA browser is built from refined Parquet via `python -m pa_edu.publish` and the UI in `pa_edu/web/`.

| File | Notes |
| --- | --- |
| `avon_grove_achievement_data.json` | Avon Grove vs Chester County PSSA/Keystone snapshot from an early achievement look |
| `avon_grove_pssa_subgroups.json` | Subgroup breakout used with that snapshot |
| `chart_expense_per_enrollment.ipynb` | Historical JupyterDash expense chart; superseded by `pa_edu.app` and then by the static site |
