Where the numbers come from

The numbers come from Pennsylvania and U.S. government sources. Detailed views link the source file for each figure.

What this project does

This site pulls those public files in, normalizes them into a database, and lays them out for browsing.

Code and reporting

All of the code is open source. You can report bugs, data problems, or feature requests at the links in the footer.
